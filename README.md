# TrackVerAA
TrackVerA&A es una aplicación orientada al registro y almacenamiento de posiciones geográficas mediante coordenadas GPS, con el objetivo de facilitar la trazabilidad de auditorías, inspecciones o recorridos realizados por usuarios dentro de una organización. El sistema permite capturar, visualizar y gestionar ubicaciones asociadas a eventos específicos, vinculándolas a perfiles de usuario con roles diferenciados: Administrador, Auditor y Usuario. Está desarrollado en Java, aprovechando su robustez, portabilidad y orientación a objetos, lo que permite una arquitectura modular y escalable. La persistencia de datos se gestiona mediante SQLite, una base de datos ligera y embebida que facilita el almacenamiento local de coordenadas sin requerir configuración compleja. Aunque actualmente se ejecuta como aplicación local, TrackVerA&A está diseñado con visión de migración futura a entorno web, lo que permitirá una experiencia más dinámica y accesible para los usuarios.
