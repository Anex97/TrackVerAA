# 4.2 Objetivos del Proyecto

## Objetivo General

Desarrollar una aplicación web para la gestión y monitoreo de flotillas
vehiculares que permita a pequeñas y medianas empresas administrar de forma
autónoma sus dispositivos GPS, reduciendo la dependencia de plataformas
externas de terceros y optimizando los tiempos de activación, seguimiento y
control de sus unidades vehiculares.

---

## Objetivos Específicos

### OE-01: Módulo de Autenticación y Control de Acceso

Diseñar e implementar un módulo de autenticación con roles diferenciados
(Administrador, Auditor y Usuario) que garantice el acceso controlado y seguro
a las funcionalidades del sistema según el perfil de cada usuario, asegurando
que ningún usuario pueda acceder a funciones que excedan sus permisos
asignados.

**Indicador de cumplimiento:** El sistema permite el inicio de sesión con
credenciales válidas, redirige al menú correspondiente según el rol y bloquea
el acceso a rutas no autorizadas para cada perfil.

---

### OE-02: Módulo de Visualización GPS e Historial de Recorridos

Desarrollar un módulo de visualización de posiciones GPS en tiempo real
mediante la integración de Leaflet.js, que permita consultar la ubicación
actual e historial de recorridos de cada unidad registrada, facilitando la
toma de decisiones operativas por parte del responsable de la flota.

**Indicador de cumplimiento:** El sistema muestra en un mapa interactivo la
posición actual de cada dispositivo registrado y permite consultar el historial
de posiciones con filtro por fecha y unidad.

---

### OE-03: Módulo de Geocercas y Alertas

Implementar un módulo de geocercas que permita definir zonas geográficas de
interés sobre el mapa y generar alertas automáticas cuando un vehículo entre
o salga de dichas zonas, incrementando el control operativo y de seguridad
de la flota.

**Indicador de cumplimiento:** El sistema permite crear, editar y eliminar
geocercas asociadas a vehículos, y genera una alerta registrada cuando se
detecta una violación de zona.

---

### OE-04: Persistencia y Arquitectura de Datos

Diseñar la arquitectura de persistencia de datos utilizando SQLite, garantizando
el almacenamiento eficiente, ordenado y recuperable de posiciones, usuarios,
dispositivos y configuraciones del sistema para su consulta, auditoría y
mantenimiento posterior.

**Indicador de cumplimiento:** El sistema opera con bases de datos SQLite
correctamente estructuradas, sin pérdida de datos entre sesiones, y permite
realizar consultas de historial con tiempos de respuesta menores a 3 segundos
bajo condiciones normales.
